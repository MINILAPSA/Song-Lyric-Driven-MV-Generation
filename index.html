GitHub 仓库

项目简介

本项目旨在构建一套以歌曲和歌词为可控条件的自动化音乐视频生成系统。通过深度整合多模态理解技术与先进的扩散模型，实现了从音乐到视觉叙事的端到端生成。系统核心由音乐信息提取、智能剧本生成、高质量视频合成与后期拼接四个模块组成，有效解决了长时序叙事断裂、角色不一致及音画同步等关键挑战，为AI驱动的艺术创作提供了新的技术路径。

方法概览

我们的技术路线采用“音乐理解 → 文本规划 → 视频生成”的流水线。首先，利用 CLAP 和 SongFormer 模型分别提取音乐的情感风格与段落结构。接着，Gemini 大语言模型作为导演智能体，融合音乐信息与歌词，生成结构化的叙事脚本与镜头指令。最后，基于扩散Transformer架构的 Wan 2.1 模型将文本指令转化为高质量的视频片段，并通过后期拼接生成完整的音乐视频。
